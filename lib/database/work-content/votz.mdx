## O Problema Encontrado
Participando de um grupo de Vôlei, notei que a pessoa responsável por montar os times passava por um processo bastante manual e 
repetitivo: escrever a lista de jogadores para o chatGpt -> Pedir para a IA organizar e formar os times -> Balancear manualmente os times
-> Repetir no próximo dia.

## A Solução Desenvolvida
Para ajudar o organizador, construí um app que no qual ele pudesse registrar todos os jogadores, com seus respectivos níveis, e que ficassem
salvos em seu celular, para não ter que reescrever novamente. Para melhorar ainda mais adicionei uma funcionalidade de montar e balancear 
os times de acordo com as habilidades dos jogadores, para que os jogos fiquem equilibrados. E pronto, todo o processo manual ficou atuomatizado
e mais prático.

## Detalhes que Influenciaram o Desenvolvimento
O desenvolvimento do aplicativo não é apenas sobre construir mas sim adaptar ao contexto do cliente/usuário, que era:
- O organizador usa apenas o celular para organizar os times.
- Também não faz sentido pagar por um banco de dados ou para publicar aplicativo na play/apple store para uma tarefa cotidiana.
Só atrasaria mais a entrega do aplicativo.
- Nem sempre o local teria internet disponível, então precisaria funcionar offline também.

Observando estes detalhes adicionei as seguintes funcionalidades:
1. PWA - Uma funcionalidade que permitia o usuário baixar e instalar o site como se fosse um app de celular mesmo,
dessa forma não foi necessário pagar a publicação do aplicativo. E também utilizar o app offline.
2. Armazenamento Local - Persistir os registros dos jogadores pela nuvem só aumentaria o orçamento do aplicativo, e não era
no momento uma necessidade, então foi decidido salvar os registros no proprio armazenamento do dispositivo do usuário. Em adição
implementei uma simples funcionalidade de poder exportar e importar uma lista de jogadores para o app.
